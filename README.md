# SQLite_ORM Project Build Instructions

## 📌 Prerequisites
Before building the project, ensure you have the following installed:
- **CMake** (version 3.14 or higher)
- **GCC/MinGW** (for Windows) or Clang (for macOS/Linux)
- **Git** (to fetch dependencies)

## 🚀 Steps to Build

### 1️⃣ Clone the current Repository and cd into that
```sh
cd GooseHubV2
mkdir build
cd build
cmake ..
```

### 2 STEP
cmake will fail in the first run so run it again
```
cmake ..
cmake --build .
```
You can run now
```
./whatever the name is.exe
```
